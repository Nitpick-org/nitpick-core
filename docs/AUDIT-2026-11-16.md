# Audit de la base — 16 novembre 2026

> Review statique + exécution des scripts + vérification des sources officielles LauzHack.
> Objectif : une base **saine, runnable et spécifique à LauzHack**, pas un template générique.

## Verdict

La base était **bonne sur la méthode** (rôles, modules profonds, tickets, agents, rituels)
mais **pas runnable** : pas de dépôt git, scripts non exécutables, `check.sh` et CI qui
passaient sans rien vérifier, pas de stack, pas de déploiement, et aucune information
LauzHack (horaires, jury, soumission, règles). En l'état, elle donnait une fausse sensation
de sécurité.

Après corrections : la méthode est conservée, les bugs bloquants sont réglés, les faits
LauzHack sont intégrés, et la base est prête à recevoir la stack.

## P2 — améliorations (laissées à l'équipe)

- **Stack** : toujours à choisir (J-4). C'est volontaire : la base est agnostique.
- **Déploiement** : à faire au J-4. Aucun hébergeur n'est imposé.
- **`docs/`** : beaucoup de documents ; la carte du README et l'ordre de lecture de
  `CLAUDE.md` évitent la dispersion. Ne pas en ajouter sans supprimer.
- **Licence** : inutile pour un hackathon ; l'IP vous appartient (règles LauzHack).
- **Agent teams** : non activées, volontairement (expérimental, coûteux, sans isolation
  worktree).
- **Mémoire persistante des agents** : non activée ; `progress/<ticket>.md` et les docs
  suffisent pour 24 h.

## Ce qui a été corrigé

- `scripts/check.sh` : vrai échec sans stack, scripts obligatoires, `--demo`.
- `.githooks/pre-commit` : exécutable, bloque `.env`, avertit sur `main`.
- `scripts/new-worktree.sh` : vérifie les collisions, copie `.env`, crée le journal.
- `scripts/ralph-once.sh` / `afk-ralph.sh` : `--max-budget-usd`, `--permission-prompts none`,
  garde-fous main / tree propre / AFK opt-in.
- `.claude/settings.json` : deny `.env`, push main/force, `--no-verify` ; hooks ; limites
  de concurrence.
- `.claude/agents/*` : contrat de membre d'équipe, curiosité, `maxTurns`, fichiers partagés.
- `CLAUDE.md` : état du projet, contrat agent, fichiers partagés, DoD, interdits.
- `README.md`, `AGENTS.md`, `PLAYBOOK.md`, `PRE-EVENT-CHECKLIST.md`, `PRD.md`, `DEMO.md`,
  `DECISIONS.md`, `QUESTIONS.md`, `IDEAS.md`, `RESEARCH.md`.
